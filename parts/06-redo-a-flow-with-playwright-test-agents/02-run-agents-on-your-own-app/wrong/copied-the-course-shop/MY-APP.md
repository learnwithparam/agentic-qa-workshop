# My app

A sample answer. The app here is made up, so the example does not need the shop. Yours is real.

## My app

Pantry Run, a small web app at https://notes.example.test where hikers save short notes about a trail and tag them.

## The flow

A signed in hiker creates a note with a title and a tag, then finds it in the list. I picked it because it is the first thing every user does.

## What the planner found

The planner found three things. An empty title should be refused. A very long title is cut in the list. A second note with the same title is allowed. I had not thought about the long title.

## What I approved

I approved the happy path, the empty title and the long title. They match what the product owner told me the app must do.

## What I rejected

I rejected a scenario that deleted every note first. It would wipe the shared test account, so I asked for a new account for each run instead.
