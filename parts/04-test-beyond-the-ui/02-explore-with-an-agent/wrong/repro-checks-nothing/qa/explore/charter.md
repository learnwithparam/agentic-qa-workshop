# Exploration charter

## Mission

Explore booking a slot, changing the basket and checking out on the release candidate. Look for ways a shopper
pays twice, pays the wrong amount, or gets two orders. The written requirements do not cover these.

## Areas

- Slot booking: double clicks, booking again, booking two slots.
- Basket quantities: zero, negative numbers, very large numbers, letters.
- Checkout: the Back button, reloading the order page, pressing Checkout twice.

## Time box

One Claude Code session of at most 40 browser actions. Stop and write up what you have when it runs out.
