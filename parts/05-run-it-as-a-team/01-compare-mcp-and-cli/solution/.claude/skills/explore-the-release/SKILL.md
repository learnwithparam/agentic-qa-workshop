# Explore the release

1. Start from the task in `qa/task.md` and use the browser tool the team chose in `qa/mcp-vs-cli.md`.
2. Try each flow in the task and write one `FINDING:` line for each thing that looks wrong.
3. Open every finding a second time to see if it repeats, and drop it if it does not.
4. Report the real findings with the steps to repeat each one.
